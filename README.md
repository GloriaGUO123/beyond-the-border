# Beyond the Border — Website prototype

A responsive, single-page website based on the uploaded 7-page outline.

## Preview locally
Open `index.html` in a modern browser. No build tools or external dependencies are required.

## Included
- Home and mission
- Key issues affecting newly arrived and cross-border children
- Research and policy evaluation sections
- Policy tracker framework
- Searchable/filterable resource directory
- About, methodology principles, and contact-form demo
- Mobile-responsive navigation

## Before publishing
- Verify and add real support services, eligibility, fees, contact details, and source/update dates.
- Add actual policy examples and citations once research is complete.
- Connect the contact form to a secure form backend; the current form is demo-only and does not send/store information.
- Review privacy, consent, accessibility, and child safeguarding practices.
